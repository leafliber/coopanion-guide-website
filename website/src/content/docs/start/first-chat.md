这页帮助你从刚安装完成走到收到第一条回复。准备一家模型服务的 API Key，并确保电脑能访问该服务。

## 跟随桌宠引导

首次启动后，Coo 会在屏幕底边用气泡询问称呼、走动习惯、模型服务和 API Key，然后提供语音模型下载入口。

点气泡中的选项即可继续。不想立即使用语音，可以先完成模型连接，稍后再到「语音输入」下载识别模型。气泡右上角的关闭按钮会结束引导；设置窗口「开始」页的「使用引导」可以重新打开。

## 在设置中连接模型

1. 右键桌宠，点设置按钮。Windows 也可单击托盘图标；macOS 可从菜单栏选择「打开设置」。
2. 打开「开始」页，在「连接模型」中选择你已开通的模型服务。
3. 检查「模型」字段。应用会填入该版本的预设名称；服务实际开放的模型及账户权限以该服务官方说明为准。
4. 在对应服务的 API Key 输入框中粘贴 Key，点「保存并开始」。需要申请 Key 时，使用页面上的「去……申请 Key」链接。
5. 等待连接测试完成。成功后应显示「已连接……」，标题旁状态为「醒着」。已有连接也可点「测试连接」复查。

:::note[API Key 与费用]
API Key 是模型平台的调用凭据，不是聊天网站的登录密码。调用可能消耗该平台的账户余额。不要把 Key 发到 Issue、聊天截图或公开文档里。数据去向与费用见[权限、费用与隐私](/safety/permissions/)。
:::

## 先发一条文字消息

1. 鼠标停在 Coo 身上，点旁边的气泡按钮；也可以双击桌宠。
2. 在输入框写一句简短的话，例如「你好，请用一句话介绍你自己」，然后发送。
3. Coo 在气泡里回复，说明本次文字对话流程已经完成。

这一步不需要下载语音识别模型。确认文字能正常使用后，再按[文字聊天与语音输入](/guides/chat-voice/)配置麦克风和说话键。

## 没有收到回复

- 「开始」显示「还没连上模型」：检查服务、模型和 Key，再测试连接。
- 显示「暂停中」：使用左栏底部的「继续」。
- 连接测试成功但对话报错：保留不含 Key 的错误提示，按[模型连接失败或没有回应](/troubleshooting/common/#模型连接失败或没有回应)逐项排查。一次连接成功不代表该服务的所有功能都已验证。
