这页按 v0.1.10 的扩展界面说明如何安装、启用和移除扩展。**World** 是连接外部环境或提供功能的扩展类型；其他类型还包括连接模型的 Provider 和提供角色装配的 Bot。

## 安装前查看来源

扩展页从 npm 软件包仓库读取结果。出现在列表中只代表包带有对应关键字，不代表项目已经审核或验证它。

先查看维护者、源码仓库、许可证、兼容性提示和包说明。扩展拥有与框架相同的文件和网络访问能力，安装前应了解[扩展权限与数据风险](/safety/permissions/)。

## 从列表安装 World

1. 打开设置，点左栏底部「高级模式」，进入「扩展」。
2. 选择顶部的「World 扩展」页签，在「扩展市场」使用「筛选：包名、描述、关键字」缩小范围。也可按下载量、最近发布或名字排序。
3. 点开包卡片查看详情。阅读弃用、兼容性或缺失声明等提示后，再点「安装」。
4. 安装成功后，在「已安装」区域点「重启进程」，确认后等待重新连接。
5. 重新连接后，检查扩展状态；如果对应 World 在「World 总览」显示「未激活」，点卡片上的电源图标「激活 World」。进入详情完成该扩展自身要求的配置。

安装第三方包和启用对应功能是不同步骤。只有该包成功加载，并按它的说明完成配置后，功能才算可用。

## 手动安装已知的包

安装 World 或 Provider 时，先选择对应的「World 扩展」或「供应商扩展」页签，然后在「手动安装」选择来源：

- **从 npm 安装**：填写维护者提供的包名，或 `包名@版本`，不要填网页链接。
- **从本机目录安装**：点「选择文件夹」，选择包含 `package.json` 的扩展目录。它通过链接接入，更新源码后可能需要重新构建；删除安装记录会保留源目录。

先点「检查有效性」核对包名、版本和类别，再点「安装」。检查通过表示符合安装要求，不代表经过安全审核。安装完成后按提示重启进程。

「Bot 模板」用于创建新实例，不会直接为当前桌宠增加功能。安装后查看「创建实例说明」和模板自己的文档；它与 World、Provider 的重启加载流程不同。

不要把网上来历不明的安装命令或包名直接粘入。开发入口与契约说明见[World 与 Provider 开发](/develop/architecture/)。

## 看懂安装状态

| 状态 | 下一步 |
| --- | --- |
| 待重启 | 重启进程，让新安装的扩展载入 |
| 已加载 | 到对应功能页检查配置；World 还需处于激活状态 |
| 加载失败 | 阅读卡片上的原因，核对扩展契约与应用版本 |
| 已安装，未加载 | 包已安装，但尚未加载到当前 Bot；World 可到管理页检查是否启用 |
| 已卸载，待重启 | 重启进程完成移除 |

“缺少浏览器构建产物”通常需要扩展维护者提供完整发布包，或由开发者在扩展目录构建；反复重启不能补出缺少的文件。

## 停用或卸载

临时不用某个 World，可在「World 总览」对应卡片上选择「停用 World」，确认后该 World 停止。眼睛图标的「对 agent 隐藏」只改变模型可见性，World 本身仍可能运行。

要移除扩展，在对应类别的「已安装」区域点「删除扩展」并确认，然后重启进程。正在使用的 World 需先停用；内置扩展不能单独删除。删除会移除共享的安装包，可能影响使用它的其他 Bot，但会保留已有配置、记忆和本地扩展源码。重要资料先[备份](/safety/data/)。
