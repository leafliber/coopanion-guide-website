这页帮助你让 Coo 完成一个可观察的小任务，并说明如何选择授权方式、拒绝请求或停止使用电脑操作。适用于 v0.1.10；四档询问方式从 v0.1.8 起提供。

## 开始前

- 先完成[模型连接](/guides/models/)。需要理解截图的任务，应选择实际支持图片的模型；只有文本能力的连接无法看懂截图。
- 关闭屏幕上的密钥、隐私资料与不想分享的通知。截图会进入模型上下文，通常覆盖主屏幕。
- macOS 需要录屏与辅助功能权限。Linux 的相关系统工具及桌面会话限制见[平台参考](/reference/platforms/)。

## Linux 所需工具

电脑操作使用 `xdotool` 输入文字、切换窗口，使用 `zenity` 提供系统确认对话框。DEB 包声明了这两项依赖；AppImage 不会替你安装系统包，需要按发行版的包管理器补齐。例如 Debian / Ubuntu：

```bash
sudo apt install xdotool zenity
```

如果提示 X 服务器无法给出屏幕画面，程序会尝试 `grim`、`spectacle`、`scrot` 或 ImageMagick 的 `import`。按实际桌面环境安装兼容工具之一，或切换到 X11 会话再试；并非每个截图工具都支持每种 Wayland 桌面。只有需要电脑操作时才处理这些依赖，文字聊天不依赖它们。

## 完成一个小任务

1. 打开一个没有敏感内容的窗口，例如空白文本编辑器。
2. 对 Coo 说清楚目标，例如「在这个空白文档里输入一行你好，先不要保存」。
3. 保持默认的 `ask-each-turn` 档位。当它询问「想用你的电脑：看屏幕、动鼠标和键盘。这一次可以吗？」时，确认当前屏幕适合分享，再点「可以」。不希望继续就选「这次不行」。
4. 留意屏幕上的实际动作与结果。任务完成后自己检查内容是否正确。

点了许可但没有动作时，先检查是否仍在使用鼠标键盘、系统权限是否生效，以及模型是否能够接收图片。必要时查看[故障排查](/troubleshooting/common/)。

## 选择什么时候先问你

在设置窗口切换到「高级模式」，打开「电脑操作」，找到「什么时候先问你」。修改后立即生效：

| 档位 | 截图、列窗口前 | 操作鼠标键盘前 |
| --- | --- | --- |
| `ask-each-turn`（默认） | 每轮第一次使用电脑操作时询问 | 与截图共用本轮许可，不会每个动作重复问 |
| `ask-before-acting` | 不询问 | 每轮第一次动手时询问 |
| `ask-once` | 不询问 | 同意后在指定时长内不再询问，过期后下次动手再问 |
| `never-ask` | 不询问 | 不询问 |

选择 `ask-once` 后，「同意管多久」默认是 **30 分钟**，可设为 1–1440 分钟。这段许可可以跨轮使用；即使还在同一轮，超过有效期也会在下次动手前重新询问。

:::caution[先看清楚截图权限]
除默认档位以外，其他三档都允许 Coo 在不询问的情况下截图和列窗口。需要先确认屏幕内容是否适合分享时，保留 `ask-each-turn`。这些设置控制内置电脑操作模块的询问，不替代系统权限。
:::

## 拒绝与超时会怎样

默认档位按轮复用许可，不是每次点击、每张截图都重新弹框。本轮选择拒绝后，仍需该许可的调用会被拒绝；下一轮需要时再问。在 `ask-before-acting` 和 `ask-once` 档位中，拒绝键鼠操作不会同时禁止截图和列窗口。

询问等待约 60 秒，没有回应不会视作同意。没有可用的桌宠气泡时，会尝试用系统对话框询问。

操作类工具默认在动作后附上新的截图，但模型也可以请求不附图。截图及回执可能继续留在上下文里，不能把关闭窗口理解为已经删除之前发送的内容。

## 手动接管与暂停的区别

电脑操作的输入工具会先检查你是否还在使用鼠标或键盘。默认等你静止约 2 秒后再操作，最多等待约 15 秒；持续操作会使该次工具调用放弃。打字还会在分段之间检查用户输入。这些是让位机制，**不是对所有动作的即时中断保证**，已经点击或输入的内容不会自动撤销。

右键菜单和设置中的「暂停」暂停的是新事件向模型的投递，事件仍可能记录，继续后会处理积压内容。它不会保证取消正在进行的模型请求或当前工具调用。需要停止应用运行时，从托盘或菜单栏选择「退出」，并检查屏幕上已经发生的动作。

## 限制或关闭电脑操作

在设置窗口切换到「高级模式」，打开「电脑操作」：

- 关闭「允许操作鼠标键盘」后，只禁止输入动作，**仍允许截图和列窗口**。
- 如果不想使用整个电脑操作模块，在「World 总览」的「电脑操作」卡片点击电源图标「停用 World」并确认。它会停止该 World，撤下相关工具。眼睛图标的「对 agent 隐藏」与停用不是同一件事。

macOS 也可在系统隐私设置中撤销对应权限；更改后重启应用。

:::caution[敏感操作请自己完成]
内置提示词要求模型把登录、密码、验证码和支付交给使用者，并在发送、删除、提交等操作前另行询问。这是对模型的行为要求，不是每个动作都有独立的强制确认锁。请自己完成敏感步骤，核对最终提交内容。
:::
