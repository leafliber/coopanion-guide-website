这页帮助你选择文字或语音输入，并判断麦克风是否工作。开始前，请先[连接模型并完成一次文字对话](/start/first-chat/)。

## 文字聊天

鼠标停在桌宠身上，点气泡按钮，或直接双击桌宠，即可打开文字输入。Coo 的回复会出现在气泡里。

如果它给出选项，可以点击选项；桌宠窗口收到键盘输入时，也支持数字键 1–3。正在文字输入框中打字时，不会把输入的数字当作选项快捷键。

## 准备语音输入

1. 打开设置 →「语音输入」，开启「开启语音输入」。
2. 选择「FunASR（本机识别）」。首次使用时，在「识别模型」一行点「下载」。模型约 240 MB，具体进度以应用为准。
3. 等待「识别模型」显示「已下载」、「识别服务」显示「就绪」。
4. 在「麦克风」中选择设备，按系统提示允许使用麦克风。对着麦克风说话，确认下方电平条有变化。

FunASR 的 SenseVoiceSmall 模型在本机识别。识别出的文字仍会进入对话并发送给你配置的模型服务；本机识别不代表整个应用离线。详见[权限与数据去向](/safety/permissions/)。

## 默认说话键

| 系统 | 默认操作 |
| --- | --- |
| Windows、Linux | 快速按一下左 Alt，紧接着再按住左 Alt 说话，松开发送 |
| macOS | 快速按一下左 Option，紧接着再按住左 Option 说话，松开发送 |

第一下应当轻点，不要一直按住。Coo 会先抬头，第二次按住后开始听；识别中的气泡会显示文字，尚未确定的部分可能继续变化。

macOS 的全局说话键需要「输入监控」权限。Linux 的 Wayland 限制见[平台差异](/reference/platforms/)。

## 改收音方式与按键

在「语音输入」的「收音方式」中选择：

- **按住说话键时收音**：按住所设的说话键，松开结束一句。
- **按一下说话键开始，再按一下停**：用说话键切换收音。
- **一直收音**：自动判断语音停顿，不需要按键。

点「说话键」按钮后，按下新的单键或组合键即可设置；连按两次可设置类似默认方式的双击按键。按 Esc 取消修改。

桌宠旁麦克风按钮上的 `KEY` 表示按键收音，`AUTO` 表示自动收音。说话键不可用时，应用会退回自动收音，悬停提示和设置页会说明原因。

:::caution[关闭语音输入才会关闭麦克风]
语音输入总开关开启时，界面说明麦克风会一直打开，再按所选方式决定何时处理、发送语音。不要把「没有按住说话键」理解成麦克风已关闭。不需要语音时，请关闭「开启语音输入」。
:::

正在听时，长按桌宠旁的麦克风按钮可立即提交这一句。普通点击则用于开关语音输入。

## 失败处理

看不到电平变化、识别服务未就绪或说话键无效时，转到[麦克风、快捷键或语音输入不可用](/troubleshooting/common/#麦克风快捷键或语音输入不可用)。Windows 还可选择系统自带识别引擎，但它依赖系统已安装的语言识别组件。
