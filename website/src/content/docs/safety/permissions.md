这页帮助你在连接模型、启用麦克风或允许电脑操作前，判断会授权什么、数据会去哪里。说明以 **Coopanion v0.1.10** 的内置功能为准；扩展可能增加自己的访问与联网行为。

:::note[v0.1.10 新增默认开启的匿名统计]
如不想发送使用统计，打开设置窗口的「习惯」页，在最下面取消勾选「匿名使用统计」，确认出现「已保存」。它与发送给模型服务的聊天请求是两条独立的数据通道，关闭统计不会停止正常的模型请求。
:::

## 哪些内容会离开电脑

| 使用场景 | 数据去向 |
| --- | --- |
| 文字聊天、桌宠互动 | 对话及进入上下文的互动信息会发送到当前配置的模型服务 |
| FunASR 语音输入 | 音频在本机识别；识别后的文字会像打字一样进入对话并发送给模型 |
| 电脑操作 | 截图、窗口信息和操作回执会进入模型上下文；图片是否发送还取决于模型与端点的图片支持 |
| 安装或浏览扩展 | 会访问 npm 等扩展来源；装入的扩展还可能连接自己的外部服务 |
| 下载语音识别模型 | 从 ModelScope 下载，失败时尝试 Hugging Face |
| 检查新版本 | 设置窗口请求 `api.github.com` 上的最新正式发布信息；查询失败时只显示当前版本 |
| 匿名使用统计（默认开启） | 使用计数、时长、设置和随机安装编号发送到项目服务器 `survey.palailab.org` |

**本地保存记录不等于记录不会发送给模型；本地语音识别也不等于整个应用离线。** 更换模型服务后，后续请求使用新的端点，可能带上已有上下文。模型服务如何保留、使用或删除请求内容，应查看该服务自己的隐私说明。

电脑操作通常看的是主屏幕，而不只是你口头指定的一个窗口。允许前关闭不想分享的窗口、通知和敏感资料。Windows 版桌宠还会在本机读取身体附近的一小片屏幕颜色，用于调整轮廓光圈；这段取色实现用于本地显示，不作为电脑操作截图发送给模型。

## 匿名使用统计

从 v0.1.10 起，统计在应用启动时尝试发送，运行期间约每 30 分钟发送一次，正常退出时也会尝试发送。每日记录按安装编号和本地日期更新；尚未成功发送的事件先存在本机。

| 统计范围 | 发送的内容与边界 |
| --- | --- |
| 安装与设备环境 | 随机安装编号、版本、系统版本和架构、语言与时区、首次启动日期、发送时间，以及内存大小和 CPU 核数；不包含硬件唯一编号 |
| 使用情况 | 运行与互动分钟数、聊天条数、触摸、回答提问、电脑操作和授权次数、模型失败次数；不包含对话文字或截图 |
| 模型用量 | 调用与失败次数、输入／输出／缓存命中 token 数；内置服务报告服务标识和模型名，自定义端点的模型名记作 `custom`，区分本地或远程类型，不发送端点地址 |
| 设置与记忆概况 | 界面语言、自启动、形象、配色、走动、语音和电脑操作设置；人设只报告是否修改，记忆只报告文件数量 |
| 扩展与一次性事件 | 注册表扩展的包名、版本和类别；本地路径或网址安装的包名记作 `private`。另有引导进度、来源选项、扩展增减和崩溃错误类名等事件 |

统计不发送 API Key、文件名与路径、提示词和记忆内容、姓名或账号。引导里「你是从哪里认识我的？」的选项也属于统计；选择「不告诉你」记录为跳过。按上游说明和公开服务端实现，IP 仅在内存中用于限流，不写入统计数据库。完整字段见 [v0.1.10 匿名使用统计说明](https://github.com/Pal-AI-Lab/Coopanion/blob/v0.1.10/docs/TELEMETRY.md)。

### 关闭后会怎样

取消勾选后不再累计新的使用统计，并清空待发的使用记录，但会尝试发送最后一条关闭事件 `telemetry_disabled`，仍附带安装编号和系统等基础字段；发送失败时可能稍后重试。关闭统计不会撤回服务器已经收到的记录。

重新开启时沿用原来的安装编号。编号与本地缓存位于 `home/companion/telemetry.json`；删除该文件只会让下次启动生成新编号，**不能代替关闭统计，也不会删除已上传的数据**。备份与卸载的影响见[数据与备份](/safety/data/)。

## API Key 如何保存

通过界面保存的 API Key 写入数据目录下 `home/providers/<端点名>/.env`。这是本地文本凭据，**不是已核实的加密保险箱**。程序也支持从启动环境变量读取同名密钥，环境变量优先。

- 不要把数据目录、`.env`、未脱敏的诊断包或包含密钥的截图提交到 GitHub。
- 备份包含凭据，应放在受保护的位置。参见[数据与备份](/safety/data/)。
- 如果密钥已经泄露，到模型服务的控制台撤销并重新生成；删除本地文件不会撤销服务端密钥。

## 权限分别做什么

| 权限或能力 | 用途 | 不授权时 |
| --- | --- | --- |
| 麦克风 | 获取语音输入 | 改用文字聊天 |
| macOS「输入监控」 | 识别全局说话键，例如左 Option | 说话键可能不可用，留意是否回退为 AUTO 自动收音 |
| macOS「录屏与系统录音」 | 电脑操作截图、读取窗口标题 | 相应电脑操作工具失败 |
| macOS「辅助功能」 | 模拟鼠标与键盘输入 | 不能执行相应键鼠操作 |
| macOS「自动化」相关提示 | 通过系统事件把应用切到前面 | 可能无法切换到目标应用 |

macOS 权限在「系统设置 → 隐私与安全性」管理。修改输入监控、辅助功能或录屏权限后，退出并重新启动 Coopanion。Windows 的麦克风权限在系统隐私设置里管理。Linux 的桌面能力取决于 X11 / XWayland 会话及系统工具，参见[平台差异](/reference/platforms/)。

语音输入总开关开启、桌宠连接正常且已获得权限时，麦克风会保持打开，音频通过本机连接送给桌宠服务。说话键决定收音处理方式，不是麦克风硬件的开关。需要停止采集时，关闭语音输入总开关；操作方法见[文字聊天与语音输入](/guides/chat-voice/)。

电脑操作默认在每轮第一次截图、列窗口或动手前询问。v0.1.8 起可在高级模式「电脑操作 → 什么时候先问你」选择四档，也可改成只在动手前问、一定时长内不重复问，或都不问。**后三档截图和列窗口均不询问**。系统权限与应用询问是两层不同的授权；详细选择与关闭方法见[电脑操作与授权](/guides/computer/)。

## 费用怎么看

Coopanion 是开源应用。调用外部模型服务可能产生费用，由你选择的服务按其规则计费，包括测试连接产生的请求。模型名称、额度和价格以服务官方说明为准。

设置里的「用量与成本」可以帮助观察消耗，但金额取决于配置的价目与可获得的用量信息。v0.1.10 的 Coo Provider 只内置了 DeepSeek 的价目，其他服务可能只有用量、没有金额。**界面没有显示金额不代表免费**；最终以服务商账单为准。连接方法见[模型连接与切换](/guides/models/)。

## 扩展的信任边界

扩展是安装到本机并加载运行的代码。只安装你信任的来源；扩展列表中的出现、下载量或安装成功，都不是安全审核证明。内置电脑操作的询问设置不能替代对其他扩展的审查，也不应当作整台电脑的通用安全边界。
