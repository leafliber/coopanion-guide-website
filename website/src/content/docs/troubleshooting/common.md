这页按你看到的症状给出排查顺序。先确认应用版本和操作系统；重装或删除文件前，先[备份数据](/safety/data/)。

## 桌宠不见了

1. Windows 查看任务栏右下角的托盘区域，必要时展开上箭头；macOS 查看屏幕顶部菜单栏。
2. 打开 Coopanion 的菜单，选择「显示桌宠」。也可进入设置 →「开始」，点「显示桌宠」。
3. 若没有图标，再打开一次 Coopanion。已有实例运行时，应用会尝试唤回桌宠。
4. 仍不出现时，退出并重新启动应用。Linux 还需检查 X11 / XWayland 与桌面窗口合成，见[平台差异](/reference/platforms/)。

关闭设置窗口不会退出 Coopanion；「隐藏桌宠」与「退出」也不是同一操作。

## 模型连接失败或没有回应

1. 打开设置 →「开始」，检查状态。显示「暂停中」时，点左栏底部的「继续」。
2. 显示「还没连上模型」时，选择实际开通的服务，核对 API Key 是否完整以及模型名称是否正确。
3. 点「测试连接」，根据错误提示处理：认证错误通常需要检查 Key；额度或余额错误应到服务商平台确认；模型不存在或无权访问应核对该账户开放的模型。
4. 网络错误时，先确认电脑能访问该模型服务。不要将 Key 粘贴到第三方“检测网站”。
5. 先用一条简单文字消息重试。如果只在截图或工具操作时失败，检查模型能力，见[模型连接与切换](/guides/models/)。

豆包等服务可能要求先在平台开通模型。应用预设名称不保证对每个账户都可用。详情以该服务官方说明为准。

## 麦克风、快捷键或语音输入不可用

1. 打开「语音输入」，确认总开关已开，「识别服务」是「就绪」。FunASR 还需「识别模型」显示「已下载」。
2. 在「麦克风」中选对设备，说话时观察电平条。没有变化时，检查系统麦克风权限、设备连接以及系统输入设备设置。
3. 默认说话方式是快速轻点左 Alt，再按住说话；macOS 对应 **左 Option**。单次长按不会触发默认的双击按键。
4. 查看按钮的 `KEY` / `AUTO` 以及悬停说明。说话键不可用会退回自动收音，设置页会给出原因。
5. 尝试在「收音方式」中临时选择「一直收音」。它能帮助区分识别问题和按键问题；测试完不需要语音时，请关闭总开关。

Windows 在系统「麦克风」隐私设置中允许桌面应用使用麦克风。macOS 在「系统设置 → 隐私与安全性」检查「麦克风」与「输入监控」，修改后退出再打开应用。Linux 的 XWayland 说话键可能受当前焦点窗口影响，可切换到 X11 会话核对。

Windows 自带识别引擎如果提示缺少识别器，检查系统语言的语音识别组件，或改回 FunASR。完整步骤见[文字聊天与语音输入](/guides/chat-voice/)。

## 语音模型下载失败

1. 在「语音输入」查看「识别模型」旁的具体错误，确认网络可用，数据目录所在磁盘有可用空间。
2. 点「重试」。此版本按顺序尝试 ModelScope 和 Hugging Face，并校验下载文件的 SHA-256。
3. 若显示 HTTP 错误或校验失败，记录脱敏后的错误文字与时间，再重试；不要从不明网盘下载文件替换模型。
4. 下载期间仍可用文字聊天。Windows 也可以按需切换系统自带识别引擎。

模型文件与临时下载位置由应用管理；排查前不要直接删除整个数据文件夹。

## 系统权限修改后仍不生效

macOS 修改输入监控、辅助功能或屏幕录制权限后，从菜单栏选择「退出」，再从「应用程序」重新打开。仅关闭设置窗口不会重新启动 Electron。

若仍有问题，先确认系统授权列表对应的是你实际打开的 Coopanion；多份旧应用副本可能造成混淆。需要哪项权限以及电脑操作的确认机制，见[权限说明](/safety/permissions/)和[电脑操作与授权](/guides/computer/)。

## 扩展装了却没有出现

先查看「扩展」页的状态，再确认是否已重启进程。如果是 World，还要到「World 总览」检查是否激活。加载失败时按卡片给出的原因处理，见[扩展安装与管理](/guides/extensions/)。

## 反馈时提供什么

向 [项目 Issue](https://github.com/Pal-AI-Lab/Coopanion/issues)提供系统版本、Coopanion 版本、复现步骤、预期结果与实际结果。Linux 加上发行版、桌面环境、X11 / Wayland 信息。

高级模式的「对话」和「运行诊断」可帮助定位问题。上传截图、日志或诊断包前，检查并移除 API Key、对话、路径中的个人信息和屏幕私密内容。不要直接公开整个数据目录。
