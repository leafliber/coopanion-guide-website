这页用于快速查找默认操作。以下以 v0.1.10 的新安装默认设置为准；已经改过的说话键和悬停按钮以你的设置为准。

## 桌宠与输入

| 想做什么 | 操作 |
| --- | --- |
| 打开文字输入 | 双击桌宠，或悬停后点气泡按钮 |
| 语音说一句话 | 快速点一下左 Alt，再按住说话，松开发送；Mac 使用左 Option |
| 开关语音输入 | 悬停桌宠后点麦克风按钮 |
| 立即提交正在识别的一句话 | 正在听时长按麦克风按钮 |
| 回答气泡选项 | 点击选项；桌宠窗口接收键盘输入且不在打字时，可按 1–3 |
| 戳桌宠 | 单击 |
| 摸头 | 在头部来回移动鼠标 |
| 拎起桌宠 | 按住拖动，再松开 |
| 打开桌宠菜单 | 右键桌宠 |

语音按钮的 `KEY` / `AUTO` 表示当前采用按键收音或自动收音。更改说话键与收音方式见[文字聊天与语音输入](/guides/chat-voice/)。

## 托盘与菜单栏

| 入口 | 用途 |
| --- | --- |
| Windows 托盘图标左键 | 打开设置 |
| Windows 托盘图标右键 | 打开包含显示桌宠、自动启动、重启与退出的菜单 |
| macOS 菜单栏图标 | 打开同类菜单 |
| Linux 桌宠右键 | 没有托盘支持时，也能通过此入口打开设置 |

「重新启动」会重启应用托管的 Core 进程。若刚修改 macOS 的系统权限，使用「退出」后重新打开整个应用。

## 设置窗口位置

普通模式提供「开始」「习惯」「装扮」「语音输入」「系统提示词」「用量与成本」。从 v0.1.9 起，修改人设不需要切到高级模式。

| 页面 | 常用操作 |
| --- | --- |
| 开始 | 连接模型、测试连接、显示桌宠、重新运行使用引导 |
| 习惯 | 修改称呼、走动、大小、音效、悬停按钮和匿名使用统计开关 |
| 装扮 | 切换形象、配色和配件 |
| 语音输入 | 总开关、识别引擎、模型下载、麦克风、收音方式和说话键 |
| 系统提示词 | 编辑人设；Ctrl+S 保存（Mac 为 Command+S），再点「重载当前 session」生效 |
| 用量与成本 | 查看应用记录的模型用量与成本 |

「系统提示词」的完整操作见[人设与系统提示词](/guides/personality/)。左上角字标下显示当前版本；检测到更新的正式 Release 时，会显示下载链接。

左栏底部的「高级模式」会显示对话、World、模型、扩展、记忆和运行诊断等入口。「回到普通模式」可收起这些页面，应用会记住模式选择。
